## 🧑‍💻 About Me

<div align="justify">

I'm a **Full-Stack Developer** with hands-on experience building **scalable SaaS platforms**, real-time systems, and production-grade APIs. I work across the entire stack — from crafting clean, performant frontends to designing backend architectures that hold up under real-world conditions.

Over the past few years, I've been building deeply in the **AI engineering** space: developing autonomous AI Agents, RAG pipelines, MCP Servers, and LLM integrations — not as experiments, but as core features shipped to production. I don't just use AI tools; I build them.

I'm detail-oriented, take full ownership of the systems I build, and operate well in fast-paced environments where architecture decisions matter. I care about code quality, security, and shipping things that actually work.
